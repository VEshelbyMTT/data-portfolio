# Data Portfolio

Public portfolio for analytics engineering, data engineering, and applied data science work.

[View the live portfolio](https://veshelbymtt.github.io/data-portfolio/)

Selected case studies include the [AI-901 refugee learning labs](ai901-refugee-labs.html),
completed in September 2026. The public case study describes the problem, design, outcome,
use of AI, and safety considerations for trainer managed Azure workshops without publishing
the private deployment assets.

The site intentionally excludes personal contact details, precise location information, private links, proprietary code, internal evidence, and confidential implementation details.

## Local preview

Open `index.html` directly in a browser or run a local static file server from this directory.

## Publishing

The repository is designed for GitHub Pages deployment from the `main` branch.
