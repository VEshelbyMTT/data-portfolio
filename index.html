How I work

Three questions I keep asking

Job titles divide data work into neat boxes. Real problems rarely cooperate, so I tend to follow the question across those boundaries.

01

What does this data actually mean?

I work with the people asking the question before deciding the grain, dimensions, metrics, or model.

  • SQL
  • Power BI
  • Microsoft Fabric
  • Unity Catalog
02

Where can it break?

I trace the data, test the assumptions, and make failure visible before somebody builds a decision on top of it.

  • Python
  • PySpark
  • Databricks
  • Delta Lake
03

Can somebody else use it?

Teaching changed what finished means to me. I build examples, checks, and documentation so the next person can use the work without needing me beside them.

  • Documentation
  • Reusable notebooks
  • Automated checks
  • Technical training

Selected work

The work I can talk about publicly

Production code and internal evidence stay private. These notes explain the problem, my part in it, and what I learned without pretending the whole result belonged to me.

Game telemetry Analytics engineering

Making player interaction data mean the same thing twice

I designed event models, dimensions, and navigation views for high volume telemetry, then built checks around the grain, mappings, identities, and journey logic most likely to go wrong.

  • Reconciled source events with what reached the model
  • Made unknown identities explicit instead of quietly dropping them
  • Defined how sessions affect attribution
  • Added regression checks for later changes
Generative AI Data engineering

Finding out whether an AI idea was worth running

I built a Voice of the Customer proof of concept across internal and external feedback. It worked. The more useful result was finding that runtime cost, not technical feasibility, was the main barrier to scaling it.

Fabric · PySpark · Microsoft Foundry · Microsoft Copilot Studio

Cross domain Applied ML

Learning a new industry quickly enough to be useful

At Metyis, I moved between forecasting, pricing, environmental risk, and sensor work across retail, industrial IoT, and aquaculture. The methods mattered, but learning the domain came first.

AI for social impact Training infrastructure

Trainer owned Azure labs for small workshops

Hosted lab platforms such as Skillable can be expensive or difficult to access for small initiatives. I could not secure internal funding, but I still wanted to support Maud's refugee learning initiative. I built a reusable Azure approach that trainers can run in a dedicated training environment or limited subscription. The first implementation supported 29 learner workspaces.

Azure · PowerShell · Entra ID · Microsoft Foundry · AI assisted engineering
